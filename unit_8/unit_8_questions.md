# Unit 8: PHP Framework - Examination Questions

## Section A: Very Short Answer Questions [2 marks each]

1. What is the purpose of HTTPS? Explain its importance in web security.

2. What is a PHP framework? List any four popular PHP frameworks.

3. Discuss one benefit of using PHP frameworks in web development.

4. What is MVC architecture? Explain briefly.

5. Define the role of Model in MVC architecture.

6. What is the purpose of View in MVC pattern?

7. Explain the role of Controller in MVC architecture.

8. What is routing in PHP frameworks?

9. What is Laravel? List any three features of Laravel.

10. What is Composer? Why is it used in PHP development?

11. What is ORM? Give an example of ORM in Laravel.

12. Differentiate between framework and library.

13. What is templating engine? Name one used in PHP frameworks.

14. What is middleware in PHP frameworks?

## Section B: Descriptive Answer Questions [10 marks each]

1. Explain the MVC architecture and its implementation in a PHP framework like Laravel. Discuss the benefits of using such a framework with practical examples.

2. Describe the MVC (Model-View-Controller) architecture. Explain how each component works and interacts with others. Discuss the advantages of using MVC pattern in web development.

3. Discuss the benefits of using PHP frameworks for web development. Compare at least three popular frameworks (Laravel, CodeIgniter, Symfony).

4. Discuss the following features of modern PHP frameworks:
   - Routing
   - Templating 
   - Authentication 
   - Authorization 
   - ORM (Object-Relational Mapping)
