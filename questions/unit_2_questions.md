# Unit 2: Control Structures and Loop - Examination Questions

## Section A: Very Short Answer Questions [2 marks each]

1. Define conditional statement and loop. Mention their importance in programming.

2. What is the purpose of the ternary operator? Provide an example.

3. Differentiate between `if-else` and `switch` statements.

4. Explain the syntax of the `while` loop in PHP.

5. What is the difference between `while` and `do-while` loops?

6. What is the purpose of the `break` statement in loops?

7. Explain the use of `continue` statement with an example.

8. Write the syntax of the `for` loop in PHP.

9. What is an infinite loop? How can you avoid it?

10. Differentiate between `break` and `continue` statements.

11. What is a nested loop? Give an example.

12. Explain the difference between `elseif` and `else if`.

13. What happens when multiple conditions are true in an if-elseif-else structure?

14. Can you use a `switch` statement with string values? Explain.

15. What is the default case in a switch statement?

## Section B: Descriptive Answer Questions [10 marks each]

1. Define conditional statement and loop. Write a program to demonstrate the use of if-else, for loop and switch statements in PHP. Compare their usage with suitable examples.

2. Explain the concept of loops in PHP. Discuss different types of loops (while, do-while, for) with their syntax and examples. Also explain when to use each type of loop.

3. Discuss the ternary operator in PHP. How is it different from the if-else statement? Write a program using both approaches to solve the same problem and compare them.

4. Explain nested conditional statements and nested loops with examples. Write a program to print a pattern using nested loops.

5. Describe the use of `break` and `continue` statements in controlling loop execution. Provide examples demonstrating their usage in different scenarios.

6. Write a PHP program that demonstrates:
   - Multiple if-elseif-else conditions
   - Switch statement with multiple cases
   - Comparison between both approaches

   Use a grade calculation system as an example.

7. Explain loop control structures in PHP. Write a program to find prime numbers between 1 and 100 using loops and conditional statements.
