# Unit 3: Array and Function - Examination Questions

## Section A: Very Short Answer Questions [2 marks each]

1. What is an indexed array in PHP? Provide an example of how to declare and iterate through it.

2. Define associative arrays in PHP. How are they different from indexed arrays?

3. What is a multi-dimensional array? Give an example.

4. List any four built-in array functions in PHP.

5. What is the purpose of the `count()` function in PHP?

6. Differentiate between `array_push()` and `array_pop()` functions.

7. What are user-defined functions in PHP? Why are they important?

8. Explain the syntax of function declaration in PHP.

9. What is the difference between parameters and arguments in functions?

10. Define variable scope in PHP. What are local and global variables?

11. What is the purpose of the `return` statement in functions?

12. Explain the `global` keyword in PHP.

13. What are string functions? List any three string functions in PHP.

14. Differentiate between `strlen()` and `str_word_count()` functions.

15. What is the purpose of date and time functions in PHP?

## Section B: Descriptive Answer Questions [10 marks each]

1. Explain the concept of multi-dimensional arrays in PHP. Write a PHP program to store and display a 2D array of student marks with proper formatting.

2. Discuss different types of arrays in PHP (indexed, associative, multi-dimensional). Write a program demonstrating the creation, manipulation, and iteration of each type.

3. Explain PHP's built-in string functions. Write a program demonstrating at least 6 string functions (e.g., strlen, substr, strpos, str_replace, strtoupper, strtolower) with examples.

4. Describe array functions in PHP. Explain the following functions with examples:
   - array_push() and array_pop()
   - array_merge() and array_slice()
   - sort() and rsort()
   - in_array() and array_search()

5. Explain the concept of user-defined functions in PHP. Discuss function declaration, passing arguments, return values, and variable scoping with suitable examples.

6. Write a detailed note on date and time functions in PHP. Create a program that:
   - Displays current date and time in different formats
   - Calculates age from birthdate
   - Finds the difference between two dates
   - Displays day, month, and year separately

7. Discuss variable scoping in PHP. Explain local, global, and static variables with examples. Also explain the use of `$GLOBALS` array.
