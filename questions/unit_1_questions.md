# Unit 1: Introduction - Examination Questions

## Section A: Very Short Answer Questions [2 marks each]

1. Define server-side scripting and mention its advantages in web development.

2. What is PHP? List any four features of PHP.

3. Differentiate between client-side scripting and server-side scripting.

4. What is XAMPP? Mention its components.

5. List the basic data types available in PHP.

6. What are constants in PHP? How do you declare them?

7. Explain the difference between `echo` and `print` statements in PHP.

8. What are the different types of operators available in PHP?

9. Define variables in PHP. What are the rules for naming variables?

10. What is the purpose of the assignment operator? Give an example.

11. Differentiate between `==` and `===` operators in PHP.

12. What are logical operators? List any three logical operators in PHP.

13. Explain the difference between pre-increment and post-increment operators.

14. What is the purpose of the concatenation operator in PHP?

15. Write the syntax for declaring a constant using the `define()` function.

## Section B: Descriptive Answer Questions [10 marks each]

1. Explain the role of PHP in web development. Discuss the advantages of using server-side scripting for dynamic web applications. Compare PHP with other server-side scripting languages.

2. Describe the process of installing and setting up a PHP development environment using XAMPP. Explain the purpose of each component (Apache, MySQL, PHP, Perl) and how they work together.

3. Discuss different data types in PHP with suitable examples. Explain type juggling and type casting in PHP with examples.

4. Explain the concept of variables and constants in PHP. Discuss the differences between them and provide examples of when to use each. Also explain variable scope briefly.

5. Write a detailed note on different types of operators in PHP. Explain arithmetic, assignment, comparison, and logical operators with suitable examples of each.

6. Discuss the importance of PHP configuration file (php.ini). Explain how to modify PHP settings and mention some important configuration directives.

7. Explain the basic syntax of PHP including PHP tags, statements, comments, and case sensitivity. Write a program to demonstrate the use of different comment styles and PHP tags.
